# 몬스터 둥지 🥚

바탕화면 위를 **도트(픽셀아트) 포켓몬**이 돌아다니는 **데스크톱 펫**이에요. 창을 따로 열 필요가 없어요. 포켓몬이 작업 표시줄 위를 걸어 다니고, 배고프거나 심심하면 말풍선으로 알려 줘요.

- **원작 도트**: 포켓몬 블랙·화이트의 움직이는 도트로 나와요.
  - 처음 실행할 때 PokeAPI 공개 저장소에서 이 컴퓨터로 한 번 내려받아 저장해요. 그다음부터는 인터넷 없이도 나와요.
  - 이 폴더 안에는 원작 그림 파일이 들어 있지 않아요.
  - 배틀에서 내 포켓몬은 원작처럼 뒷모습으로 나와요.
  - 원작 도트에는 표정이 없어서, 기분은 머리 위 아이콘으로 보여 줘요(♪ 기쁨, 💧 슬픔, ! 놀람). 잘 때는 움직임을 멈추고 Zzz가 떠요.
- **직접 찍은 도트(예비용)**: 인터넷이 안 되거나 설정에서 「원작 도트로 보기」를 끄면 나와요.
  - 공식 디자인을 보고 48×48로 직접 찍은 도트예요.
  - 표정 6종(보통 · 기쁨 · 잠 · 슬픔 · 놀람 · 기절)과 걷기 프레임이 있어요.
- 알, 아이템, 응가, 별까지 전부 도트예요. 글꼴도 한글 도트 폰트 「갈무리」를 써요.
- **말 걸기 (Claude)**: 궁금한 걸 물어보면 포켓몬이 자기 말투로 대답해 줘요. Anthropic의 Claude API 키가 필요해요. 자세한 내용은 아래 「Claude와 대화하기」를 보세요.
- **여러 가지 움직임**: 걷기, 통통 튀며 달리기, 두리번두리번, 하트 포즈, 신나서 제자리 점프, 꾸벅꾸벅 졸기를 알아서 해요. 커서가 가까이 오면 커서 쪽을 쳐다봐요.

> 개인용 팬게임이에요. 포켓몬과 캐릭터 이름의 권리는 Nintendo · Creatures · GAME FREAK에 있어요. 혼자 즐기는 용도로만 쓰고, 다른 사람에게 배포하거나 판매하지 마세요.

## 1. 실행하기

### Windows (가장 쉬운 방법)
- **`MonsterNest-1.0.0-portable.exe`**를 더블클릭하면 바로 실행돼요. Node.js를 설치할 필요가 없어요.
- 서명되지 않은 프로그램이라 SmartScreen 경고가 뜰 수 있어요. 그럴 때는 **추가 정보 → 실행**을 누르세요.
- 이 실행 파일은 아이콘이 기본 Electron 모양이에요. 몬스터 둥지 아이콘이 들어간 실행 파일은 아래의 `make-exe-windows.bat`로 만들 수 있어요.

### Windows (소스로 실행)
1. **Node.js**를 설치해요. https://nodejs.org 에서 왼쪽의 **LTS** 버전을 받으면 돼요. 한 번만 설치하면 돼요.
2. 이 폴더의 **`start-windows.bat`**을 더블클릭해요.
   - 처음 실행할 때만 1~3분 동안 필요한 파일을 내려받아요.
   - 그다음부터는 바로 켜져요.
3. 화면 가운데에 **알 고르기** 창이 뜨면 시작이에요!

### Mac
1. https://nodejs.org 에서 **LTS** 버전을 설치해요.
2. **`start-mac.command`**를 더블클릭해요.
   - "확인되지 않은 개발자" 경고가 뜨면, 파일을 우클릭한 뒤 **열기**를 누르세요.

### 설치 파일(.exe)로 만들기 (Windows, 선택)
- **`make-exe-windows.bat`**을 더블클릭하면 `dist` 폴더에 `MonsterNest-Setup-1.0.0.exe`가 만들어져요.
- 이 설치 파일로 설치하면 시작 메뉴에 등록되고, 그다음부터는 Node.js 없이도 실행돼요.
- 서명되지 않은 프로그램이라 Windows SmartScreen이 경고할 수 있어요. 그럴 때는 **추가 정보 → 실행**을 누르세요.

## 2. 조작법

| 동작 | 하는 일 |
|---|---|
| **클릭** | 쓰다듬기 (기분 +3, 콩 뛰어요) |
| **더블클릭** | 상태창 열기 (모든 기능 버튼이 여기 있어요) |
| **우클릭** | 빠른 메뉴 (밥 · 놀기 · 씻기 · 재우기 · 모험) |
| **드래그** | 들어서 옮기기. 휙 던지면 날아가요 |
| **마우스 올리기** | 이름 · 레벨 · 상태 바를 미리 보여 줘요 |
| **응가 클릭** | 치우기 (청결 +8) |
| **상태창 → 말 걸기** | Claude로 포켓몬과 대화하기 |
| **작업 표시줄 아이콘** | 메뉴, 숨기기, 화면 가운데로 불러오기, 설정, 종료 |

포켓몬이 없는 바탕화면 부분은 클릭이 그대로 통과해요. 그래서 평소처럼 컴퓨터를 쓰면 돼요.

## 3. 게임 내용

### 포켓몬

| 알 | 타입 | 진화 | 특기 |
|---|---|---|---|
| 뮤 | 에스퍼 | 없음 (둥실 떠다녀요) | 사이코키네시스가 절대 빗나가지 않아요 |
| 메타몽 | 노말 | 없음 | 「변신」으로 상대 기술을 그대로 따라 해요 |
| 피카츄 | 전기 | LV 12 라이츄 | 10만볼트가 상대를 마비시켜요 |
| 이브이 | 노말 | LV 12에 **직접 골라** 부스터 · 샤미드 · 리피아 · 쥬피썬더 | 전광석화가 빗나가지 않아요 |

- 알을 고를 때 이름을 비워 두면 포켓몬 이름으로 불러요. 이때는 진화하면 이름도 같이 바뀌어요(피카츄 → 라이츄). 직접 지은 이름은 진화해도 그대로예요.
- 피츄는 키울 수는 없고, 모험에서 만나면 도감에 기록돼요.

### 돌보기
- **포만감 · 기분 · 체력 · 청결**은 시간이 지나면 줄어요.
- 프로그램을 꺼 둔 동안에도 천천히 줄어요. 최대 12시간까지만 반영돼요.
- 체력이 바닥나면 스스로 잠들고, 다 자면 알아서 일어나요.
- 상태가 25 아래로 떨어지면 Windows 알림으로 알려 줘요. 설정에서 끌 수 있어요.
- 포켓몬이 죽는 일은 없어요. 대신 슬픈 표정을 짓고 느릿느릿 걸어요.

### 밥

| 이름 | 가격 | 효과 |
|---|---|---|
| 오랭열매 | 무료 | 포만감 +15 |
| 포핀 | 5코인 | 포만감 +28, 기분 +12 |
| 특제 도시락 | 15코인 | 포만감 +60, 경험치 +8 |

### 모험 (턴제 배틀)
- 비슷한 레벨의 야생 포켓몬과 싸워요. 이기면 경험치와 코인을 받아요.
- 상성: 불꽃은 풀에, 풀은 물에, 물은 불꽃에, 전기는 물에, 에스퍼는 노말에 강해요.

### 별 잡기
- 바탕화면 여기저기에 12초 동안 별이 나타나요. 잡을수록 기분이 좋아져요.

### 움직임
- 포켓몬은 가만히 있지 않고 알아서 이런 행동을 골라서 해요. 기분과 체력에 따라 하는 행동이 달라져요.

| 행동 | 언제 | 모습 |
|---|---|---|
| 걷기 | 언제나 | 바탕화면을 천천히 걸어 다녀요 |
| 통통 달리기 | 기분 · 체력이 좋을 때 | 콩콩 뛰면서 빠르게 이동해요 |
| 두리번두리번 | 언제나 | 제자리에서 좌우를 둘러보고(?) 커서가 있으면 그쪽을 봐요 |
| 포즈 | 기분이 좋을 때 | 콩 뛰고 하트를 띄워요 |
| 신나서 점프 | 기분이 아주 좋을 때 | 제자리에서 여러 번 뛰어요 (♪) |
| 꾸벅꾸벅 | 체력이 떨어졌을 때 | 고개를 끄덕이며 졸아요 (z). 진짜로 자는 건 아니에요 |
| 따라가기 | 기분이 좋고 커서가 가까울 때 | 커서를 쫓아와요 |

- 직접 찍은 도트일 때는 눈도 깜박여요. 원작 도트는 GIF 안에 원래 움직임이 들어 있어요.
- 화면 끝에서도 몸이 잘리지 않게 멈춰요.

### 도감
- 키워 본 포켓몬과 모험에서 만난 포켓몬이 기록돼요. 모두 10종이에요.

### 내 그림으로 바꾸기 (AI로 만든 캐릭터도 OK)
- 상태창(더블클릭)에서 **내 그림으로 바꾸기**를 누르고 그림 파일을 고르면, 그 캐릭터가 바탕화면을 돌아다녀요.
- **48×48 도트로 바꿔서 쓰기**(기본으로 켜져 있음)를 켜 두면 어떤 그림이든 도트로 다시 찍어 줘요. 외곽선과 명암도 넣어 줘요.
- 흰색처럼 한 가지 색으로 된 배경은 자동으로 지워요.
- 레벨, 능력치, 진화 같은 게임 기록은 그대로 유지돼요. **원래 모습으로**를 누르면 되돌아가요.
- AI로 내 캐릭터를 만들고 싶다면 **`AI-캐릭터-프롬프트.md`**의 프롬프트를 ChatGPT나 Gemini에 붙여 넣으세요.

## 4. Claude와 대화하기
포켓몬에게 궁금한 걸 물어보면 Claude(Anthropic의 AI)가 포켓몬 말투로 짧게 대답해 줘요. 대답은 포켓몬 머리 위 말풍선과 대화창에 같이 나와요.

### 처음 설정 (한 번만)
1. https://console.anthropic.com 에 가입하고 결제 수단을 등록한 뒤 **API Keys**에서 키를 만들어요. 키는 `sk-ant-`로 시작해요.
   - 어린이라면 꼭 어른과 함께 해 주세요. 질문할 때마다 요금이 나가요.
2. 작업 표시줄 아이콘 → **설정 → Claude API 키 설정…**을 누르고, 키를 붙여 넣은 뒤 **저장**을 눌러요.
   - 상태창(더블클릭) → **말 걸기** → **API 키 설정**에서도 할 수 있어요.

### 말 걸기
- 상태창의 **말 걸기 (Claude)** 버튼이나, 작업 표시줄 아이콘 메뉴의 **말 걸기 (Claude)**를 눌러요.
- 입력 칸에 질문을 쓰고 **Enter**나 **보내기**를 눌러요. 기다리는 동안 포켓몬 머리 위에 「…」가 떠요.
- 앞의 대화를 기억하고 이어서 대답해요. 대화는 최근 20개까지 이 컴퓨터에만 저장돼요. **대화 지우기**로 지울 수 있어요.
- 대답해 주면 포켓몬 기분이 조금(+2) 좋아져요. 자는 중에는 말을 걸 수 없어요.
- 포켓몬은 어린이도 쓴다고 생각하고 대답해요. 숙제는 답만 알려 주지 않고 푸는 방법을 같이 생각해 줘요. 이름, 주소 같은 개인 정보는 묻지 않아요.

### 모델과 요금 (작업 표시줄 아이콘 → 설정 → Claude 모델)

| 모델 | 특징 | 질문 1번 요금 (대략) |
|---|---|---|
| **Claude Opus 5.5** (기본) | 가장 똑똑해요 | 약 1~2센트 (15~30원) |
| **Claude Haiku 5.5** | 빠르고 아주 저렴해요 | Opus의 약 30분의 1 |

- 요금은 질문과 대화 길이에 따라 달라져요. 정확한 사용량은 console.anthropic.com에서 확인하세요. 거기서 월 사용 한도도 정할 수 있어요.

### 키 보안
- 키는 Windows/Mac의 암호화 기능으로 이 컴퓨터에만 저장돼요(`claude-key.bin`). 게임 화면과 `save.json`에는 들어가지 않아요.
- 키를 지우려면 **API 키 설정 → 저장된 키 지우기**를 누르세요.

### 대화가 안 될 때
| 안내 | 해결 |
|---|---|
| API 키가 맞지 않아요 | 키를 다시 복사해서 저장하세요 |
| API 크레딧이 부족해요 | console.anthropic.com에서 결제 상태를 확인하세요 |
| 질문이 너무 많았어요 | 1분쯤 기다렸다가 다시 하세요 |
| 인터넷에 연결되지 않았어요 | 인터넷 연결을 확인하세요 |

## 5. 설정 (작업 표시줄 아이콘 → 설정)
- **항상 다른 창 위에 표시**: 끄면 다른 창 뒤로 숨고, 바탕화면이 보일 때만 보여요.
- **컴퓨터 켤 때 자동 실행**
- **배고플 때 알림 받기**
- **원작 도트로 보기**: 끄면 직접 찍은 도트로 바뀌어요.
- **크기**: 보통(2배) / 크게(3배)
- **Claude API 키 설정…**, **Claude 모델**: 위의 「Claude와 대화하기」를 보세요.
- **처음부터 다시 키우기**

## 6. 저장 위치
- Windows: `%APPDATA%\MonsterNest\save.json`
- Mac: `~/Library/Application Support/MonsterNest/save.json`
- 내려받은 원작 도트는 같은 폴더의 `sprites` 폴더에 저장돼요.
- Claude API 키는 같은 폴더의 `claude-key.bin`에 암호화해서 저장돼요.

## 7. 문제 해결
- **리눅스**: 지원하지 않아요. 리눅스는 마우스 이동 정보를 넘겨주지 않아서 포켓몬을 클릭할 수 없어요.
- **포켓몬이 안 보여요**: 작업 표시줄 아이콘에서 **화면 가운데로 불러오기**를 누르세요.
- **게임이나 영상 위에 떠서 거슬려요**: 아이콘 메뉴에서 **잠깐 숨기기**를 누르거나, **항상 다른 창 위에 표시**를 끄세요.
- **이름 입력 칸에 글자가 안 써져요**: 입력 칸을 한 번 클릭한 뒤 입력하세요.

```
monster-nest/
├─ main.js            투명 창 · 작업 표시줄 아이콘 · 메뉴 · 저장 · Claude API 호출
├─ preload.js         화면과 메인 프로세스 연결
├─ renderer/
│  ├─ index.html
│  ├─ style.css
│  ├─ art.js          포켓몬 디자인과 데이터
│  ├─ pixel.js        도트 엔진 (48×48 스프라이트 · 표정 · 걷기 프레임 · 외곽선 · 명암)
│  ├─ game.js         움직임 · 돌보기 · 배틀 · 미니게임 · Claude 대화창
│  └─ fonts/          갈무리 도트 폰트 (SIL OFL 1.1)
├─ assets/            아이콘
├─ start-windows.bat  Windows 실행
├─ make-exe-windows.bat  설치 파일 만들기
├─ start-mac.command  Mac 실행
└─ AI-캐릭터-프롬프트.md  AI로 내 도트 캐릭터 만들기
```
